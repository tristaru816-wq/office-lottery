⚙️ 首次使用需要配置 Firebase（免费）

只需 5 分钟，配置一次后所有人都能实时同步：

  1. 打开 Firebase 控制台，登录 Google 账号
  2. 创建项目 → 添加 Web 应用 → 复制配置代码
  3. 左侧菜单「Realtime Database」→ 创建数据库 → 选择「测试模式」启动
  4. 把下面的 firebaseConfig 替换成你的配置
  5. 保存 HTML，发给大家或上传到任意免费空间（Netlify / GitHub Pages）

免费额度足够办公室使用（100 人同时在线、1GB 存储）。数据存在你自己的 Firebase 项目里，安全可控。
